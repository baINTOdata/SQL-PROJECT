# sql-data-analytics-project
sql-data-analytics-project

Une collection complète de scripts SQL pour l’exploration, l’analyse et le reporting de données. Ces scripts couvrent différentes analyses telles que l’exploration de bases de données, les mesures et indicateurs, les tendances temporelles, les analyses cumulatives, la segmentation, et bien plus encore.

Ce dépôt contient des requêtes SQL conçues pour aider les analystes de données et les professionnels de la BI à explorer, segmenter et analyser rapidement des données au sein d’une base de données relationnelle. Chaque script se concentre sur une thématique analytique spécifique et illustre les bonnes pratiques en matière de requêtes SQL.
